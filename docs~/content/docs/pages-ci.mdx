이 저장소의 문서는 `docs~/` 폴더의 **Fumadocs + Next.js** 프로젝트로 작성하고, GitHub Actions에서 정적 export(`next build` → `out/`)한 결과를 GitHub Pages에 배포합니다.

> `docs~` 폴더 이름은 끝의 `~` 때문에 Unity가 임포트 대상에서 무시합니다. 문서 소스가 패키지 에셋으로 들어가지 않습니다.

## 디자인 공유

레이아웃·색상·로고 같은 공통 디자인은 [`ach-fumadocs-theme`](https://github.com/achieveonepark/ach-fumadocs-theme) 패키지에서 가져옵니다. 테마를 한 곳에서 고치면 모든 패키지 문서가 다음 빌드에서 동일하게 반영됩니다.

## 빌드 흐름

1. `docs~/content/docs/**` 의 MDX 문서를 작성합니다.
2. `main` 브랜치에 push 하면 `.github/workflows/docs.yml` 워크플로우가 실행됩니다.
3. `docs~`에서 `npm ci && npm run build`로 정적 사이트를 만듭니다.
4. `actions/deploy-pages`로 GitHub Pages에 배포합니다.

## 로컬 미리보기

```bash
cd docs~
npm install
npm run dev      # http://localhost:3000
npm run build    # 정적 export 검증 (out/)
```

## 경로(basePath)

GitHub Pages project 사이트는 `/<repo>/` 경로에서 서비스되므로 `next.config.mjs`에서 `basePath`를 저장소 이름으로 맞춥니다. 공통 설정 `achNextConfig({ repo })`가 이를 처리합니다.
